# Проект интернет-магазина



##  Функциональность

- **Главная страница - Простая приветственная страница** 
- **Страница контактов - Форма обратной связи с полями:** 
  1. Имя
  2. Телефон
  3. Сообщение
- **Обработка формы - Принимает и отображает данные, введённые пользователем**

## Функции

**home(request)**

Отображает главную страницу.


**contacts(request)**

Отображает страницу с формой обратной связи.


**contact(request)**

Обрабатывает отправку формы через POST-запрос.


## Установка:

+ Установите на свой компьютер GitHub.
+ Клонируйте репозиторий с GitHub  с помощью веб-URL.


## Использование:

Запуск django приложения:
python manage.py runserver
